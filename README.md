# Traffic Light Controller Using Arduino Uno

## Project Overview
This project simulates a traffic light controller using Arduino Uno and the Wokwi online simulator.

## Components
- Arduino Uno
- Red, yellow, and green LEDs
- Three 220Ω resistors
- Connecting wires

## Working
The Arduino controls three LEDs through digital output pins.

- Red LED turns ON for 5 seconds.
- Green LED turns ON for 4 seconds.
- Yellow LED turns ON for 2 seconds.
- The sequence repeats continuously.

## Concepts Used
- GPIO (General Purpose Input/Output)
- Digital output control
- Timing delays
- Basic programming using loops and functions
